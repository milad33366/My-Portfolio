# MIPI CSI FPD-Link Serializer / Deserializer

## معرفی پروژه

این پروژه شامل طراحی سخت‌افزاری یک برد مبتنی بر Serializer / Deserializer برای انتقال داده‌های تصویری از طریق لینک FPD-Link و رابط MIPI CSI است.

در این پروژه، مستندات فنی تراشه‌ها و الزامات طراحی رابط‌های ارتباطی مطالعه و در طراحی شماتیک و PCB اعمال شد. برد با ساختار چهارلایه طراحی شده است.

یکی از چالش‌های اصلی این پروژه، طراحی مسیر ارتباطی FPD-Link با فرکانس کاری حدود 2GHz بود. همچنین پیاده‌سازی قابلیت Power over Coax (PoC) و انتقال تغذیه از طریق کابل کواکسیال، ملاحظات طراحی سخت‌افزار را پیچیده‌تر می‌کرد.

## قابلیت‌ها و مشخصات فنی

- طراحی سخت‌افزاری مدار Serializer / Deserializer
- پشتیبانی از رابط تصویری MIPI CSI
- استفاده از لینک ارتباطی FPD-Link با فرکانس کاری حدود 2GHz
- پیاده‌سازی قابلیت Power over Coax (PoC)
- طراحی PCB چهارلایه
- طراحی بر اساس مطالعه و بررسی مستندات فنی قطعات و الزامات رابط‌های ارتباطی

## ملاحظات و چالش‌های طراحی سخت‌افزار

### 1. طراحی لینک پرسرعت FPD-Link

فرکانس کاری حدود 2GHz در لینک FPD-Link، طراحی مسیرهای سیگنال را به یکی از چالش‌های اصلی پروژه تبدیل می‌کرد. در این بخش، ملاحظات مربوط به مسیریابی سیگنال‌های پرسرعت و حفظ یکپارچگی سیگنال (Signal Integrity) اهمیت ویژه‌ای داشت.

### 2. پیاده‌سازی Power over Coax (PoC)

پیاده‌سازی PoC با هدف انتقال تغذیه از طریق کابل کواکسیال انجام شد. هم‌زمانی انتقال سیگنال پرسرعت و تغذیه روی یک مسیر، نیازمند توجه به ملاحظات طراحی مدار تغذیه و مسیر سیگنال بود.

### 3. طراحی رابط MIPI CSI

طراحی و مسیریابی رابط MIPI CSI با توجه به الزامات الکتریکی و توصیه‌های فنی ارائه‌شده در مستندات قطعات انجام شد.

### 4. طراحی PCB چهارلایه

ساختار PCB چهارلایه با در نظر گرفتن الزامات طراحی مدارهای پرسرعت و ملاحظات مربوط به مسیرهای سیگنال طراحی شد.
